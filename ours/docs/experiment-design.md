# 多轮用户意图推断：一页实验设计（讨论稿）

**研究目标。** 区分“仍有效但当前请求省略的历史偏好”与“已被用户修改的旧偏好”，检验历史利用、纠正更新及必要澄清。研究对象是固定模型下的信息策略与交互行为，暂不训练模型。四个benchmark仅提供场景或来源上下文，新增控制任务的成绩不代表原版benchmark成绩。

**核心任务。** 以小组可人工逐条审核的配对任务作为讨论单位，优先审核已有Pi/Life讨论子集32条；MemPA/ProAgent各有8条讨论任务，可作跨场景补充。每组固定场景、当前请求和候选行动，只改变历史证据或私有目标：S保留有效旧偏好，R在历史中明确替换旧偏好；U0/U1在首次披露前给智能体完全相同的可见信息，但私有目标相反，必须针对性询问才可识别。目标、有效证据和纠正脚本由私有oracle记录，不向智能体暴露条件标签、配对ID或未来信息。扩展数据仍保留供覆盖性检验，不把改写与干扰变体计作独立任务来源。

**交互过程。** 每条任务有三个检查点：①当前请求省略偏好；②用户在固定时点明确、持久地纠正偏好；③新会话再次省略偏好。每个检查点最多提问一次，脚本用户只披露被问到的目标偏好；智能体选择候选行动或弃权。纠正不取决于前一步是否答错。所有行动为模拟选择，不执行真实下单、消息发送或应用操作。

**基线。** B0=current-session，不读取历史会话；保留当前会话的请求、澄清答复与纠正，否则无法测量多轮更新。B1=history-retrieval，在同模型、提示词、行动空间和响应预算下，用固定embedding检索过去用户历史top-2并按时间呈现。B0并非“每步只给最后一条消息”，若讨论中要求该字面定义，应新增独立基线，不重命名已有结果。按任务与策略隔离状态；分别报告有效证据是否被检索到及证据可见时的行动表现，区分检索遗漏与判断错误。

**三项主要指标。** ①行动正确性：分S/R/U及检查点报告首次直接正确率、澄清后最终正确率、纠正后的更新成功率；新会话的首次直接正确才用于衡量无需重问的保持表现，最终正确不能替代它。②无依据假设：已有规则统计“结构化偏好断言与金标准/有效引用不一致”，它只是代理指标，不能等同所有自然语言无依据假设；同时报告断言覆盖率，并人工按当时可见证据审核抽样断言与无证据直接行动。③提问负担：每任务问题数、已知证据下的重复确认、无关问题；在缺信息时提问属于必要澄清，不应单纯扣分。三项并列呈现，不以单一总分掩盖取舍。

**分析与有效性。** 按S/R和U0/U1配对比较B0/B1，报告计数、差值及来源/模板聚类的不确定性；MemPA/ProAgent还须考虑同一用户/参与者内的相关性。U配对重点看是否澄清及披露后行动，不把披露前碰巧猜中作为推断成功。当前协议是单偏好、显式纠正、有限候选、三检查点的受控实验；它不能证明开放任务、隐式纠正或长程原生工具执行能力。U条件明确提示旧默认不适用，检验的是显式不确定信号下的澄清。

**当前状态与下一步。** 此前按后续授权已扩展并运行推理实验：Pi/Life为4,608条任务，MemPA/ProAgent为5,952条任务；两模型、两基线均无训练。规模扩展不替代小组设计讨论或人工验证。本次只校准设计表述，不启动新实验、不更改冻结运行或历史评分。下一步先审核上述小组的目标、配对等价性、纠正措辞及三项评分定义，再决定是否追加full-history诊断上界或新的状态管理策略。旧Pi/Life语义裁判存在跨会话可见性混淆，不用于确认主要结论；MemPA/ProAgent已改为单检查点输入，但仍须人工校准。
